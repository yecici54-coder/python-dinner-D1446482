## 三、思考題解答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
**答：** 因為 `"4"` 在 Python 中是字串型別 (`str`)。字串與數字無法直接進行除法運算，必須先透過 `int()` 轉換為整數 (`int`)，才能正確執行數學除法計算每人費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**答：** 
1. 先扣折價券：$1,200 - 100 = 1,100$ 元。
2. 再算 10% 服務費：$1,100 \times 0.10 = 110$ 元。
3. 應付總額：$1,100 + 110 = 1,210$ 元（比規定的 1,220 元少 10 元）。
* **原因**：餐廳的服務費是以「原始消費金額」計算的。若先扣折價券，計費基數會變小，導致服務費與總金額不符合餐廳的實際計費規則。
